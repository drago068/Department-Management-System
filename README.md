# NEXUS College Management System (React Native)

A modern, full-featured College Management & Attendance System built with **React Native** and **Expo**.

## ✨ Features

- **Common Campus Hub**: Centralized portal showcasing official circulars, master timetables, academic calendar, Q-Fix redressal system, campus facilities, and upcoming milestones.
- **Student Portal**:
  - Student authentication & dashboard
  - Subject-wise attendance tracking & circular progress indicators
  - Student Profile & Edit Profile with locked academic records & editable contact info
  - Attendance detail view
- **Staff Portal**:
  - Faculty authentication & dashboard
  - Mark Attendance & session management
  - Faculty Profile & Edit Profile with institutional credentials
  - Attendance review & history
- **Admin Portal**:
  - Senior administration authentication & dashboard
  - Real-time attendance oversight & analytics
  - Senior Governance Profile & Edit Profile
  - Report & Excel management
- **Smooth Aesthetics & UX**:
  - Modern typography and curated palettes
  - BlurView glassmorphism and subtle animations
  - Responsive layout optimized for mobile and web

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- npm or yarn
- Expo CLI (`npx expo`)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Muthu-glitch45/CMS-REACT-NATIVE.git
   cd CMS-REACT-NATIVE
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   # Run for Web
   npm run web
   # or
   npx expo start --web

   # Run for Mobile / Expo Go
   npx expo start
   ```
